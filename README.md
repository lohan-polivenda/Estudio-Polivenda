# POLIVENDAS Estúdio de Fotos

App HTML local para planejar, produzir, renomear e enviar ao Google Drive as fotos de produtos.

- `_sistema/organizador-fotos.html` — o app
- `_sistema/servidor.js` — servidor local (Node)
- `_sistema/abrir-estudio.vbs` — atalho para abrir no Windows

Fotos, dados e chaves de acesso não são versionados.
